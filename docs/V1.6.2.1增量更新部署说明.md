# TDSQL-SQLCheck V1.6.2.1 增量更新部署说明（针对内网 v1.6.1.9）

## 1. 适用场景与介质

- **适用基线**：内网当前运行版本为 **v1.6.1.9**（亦兼容 v1.6.1.8 / v1.6.2.0）。
- **补丁介质**：
  - `tdsql-sqlcheck-v1.6.2.1-patch.tar.gz`
  - `tdsql-sqlcheck-v1.6.2.1-patch.tar.gz.sha256`

---

## 2. 增量更新包含的文件清单

| 变动文件 | 变更目的 |

| `backend/engine/rules/index.py` | R061 索引命名规则剥离反引号（消除 78.6% 系统性误报，保留 DDL 原始大小写） |

| `apply_patch.sh` | 自动化备份、增量覆盖与平滑重启工具 |

---

## 3. 三步极速部署操作

### 第一步：上传并校验
```bash
cd /tmp
sha256sum -c tdsql-sqlcheck-v1.6.2.1-patch.tar.gz.sha256
```

### 第二步：解压补丁
```bash
tar -zxvf tdsql-sqlcheck-v1.6.2.1-patch.tar.gz
cd tdsql-sqlcheck-v1.6.2.1-patch
```

### 第三步：一键应用补丁
```bash
# 传入目标安装根目录（默认为 /opt/tdsql-sqlcheck/current）
sudo ./apply_patch.sh /opt/tdsql-sqlcheck/current
```

---

## 4. 自动化处理与验证说明

1. **自动备份**：补丁脚本在执行替换前，会自动将当前受影响的原版文件备份至 `/opt/tdsql-sqlcheck/current/backup_pre_v1.6.2.1_<时间戳>` 目录中。
2. **自动重启**：覆盖完成后，脚本会自动重启服务（优先调用 systemd，回退支持 supervisord 或 nohup 进程管理）。
3. **即时生效**：无需重新安装 Python 虚拟环境依赖，即刻生效。
