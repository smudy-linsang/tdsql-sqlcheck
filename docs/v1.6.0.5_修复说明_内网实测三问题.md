# v1.6.0.5 修复说明（内网实测三问题）

> 版本：v1.6.0.5　基线：v1.6.0.4　依据：`docs/v1.6.0.4_内网实测三问题排查与解决方案.md`（含根因更正提交）

## 一、Fix1 业务库枚举失败面过大

**根因**：旧版要求实例的**全部** Proxy 连接成功，任一不可达/鉴权失败即整实例枚举失败。
内网分布式与**集中式普遍双 Proxy（主+备）**，备 Proxy 不可达导致大面积失败——与实例形态无关。

**修复**（`backend/services/zk_scan_enrich_service.py`）：
- 逐端点捕获异常不抛出，改为"**≥1 个 Proxy 成功即可**"：
  - 0 成功 → `([], "NO_AVAILABLE_PROXY")`（不造假数据）；
  - 1 成功 / 多个成功且一致 → `source="proxy_show"`；
  - 多个成功但不一致 → **取并集**，`source="proxy_show_partial"`（不整实例失败）。
- `_proxy_endpoints` 保证**主 Proxy（host:port）排在最前**，已知可达优先。

## 二、Fix2 多 worker 部署下"会话已过期"（410）频发

**根因**：发现会话与导入预览存在**进程内存**，`uvicorn --workers N` 时预览请求
落到无会话的 worker 即 410。

**修复**（新模块 `backend/services/zk_discovery_session_store.py` + `database.py` 建表）：
- 新增元数据库表 `zk_discovery_sessions` / `zk_discovery_previews`（幂等 IF NOT EXISTS），
  会话/预览跨 worker 共享；
- business/monitor 口令以现有 Fernet `encrypt_password` **加密入库**
  （旧内存态还是明文，入库顺带提升安全）；发现项本身脱敏（user/password/database 不入库）；
- 过期判据改 `time.time()` 墙上时钟（monotonic 是进程内时钟，不能用于共享存储）；
- 属主校验（他人会话/预览 403）、Mock 禁入预检（409）、提交后销毁预览防重放（410）语义不变；
- `backend/api/zk_discovery.py` 删除全部内存字典与锁，改为薄封装调用存储模块。

## 三、Fix3 关闭导入弹窗后旧勾选残留

**根因**：导入弹窗关闭不清空发现表勾选与预览状态，再次打开时旧选择混入新预览。

**修复**（`frontend/index.html` + `frontend/static/js/app.js`）：
- 发现表增加 `ref="zkDiscoveryTableRef"`；导入弹窗绑定 `@close="closeZkImport"`；
- `closeZkImport` 清空 `zkSelected`/`zkImportSelected`/`zkImportRows`/`zkImportPreviewId`
  并调用表格 `clearSelection()`；提交成功路径同样触发（选择已消费，属正常）。
