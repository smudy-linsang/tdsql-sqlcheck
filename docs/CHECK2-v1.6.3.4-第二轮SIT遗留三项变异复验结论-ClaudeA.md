### S2-03 网关用例顺序相关 —— ✅ 关闭

**Q 的修法比我给的方案更对，这点要记一笔。**我建议的是 `monkeypatch.setenv("AUTH_ENABLED","false")` 一行。Q 指出这不够，并双管齐下：

```python
monkeypatch.setenv("AUTH_ENABLED", "false")
import backend.config as _cfg
monkeypatch.setattr(_cfg, "auth_enabled", lambda: False)
```

**我核实了他的理由，成立**：`backend/config.py:90-95` 的 `auth_enabled()` 是**先读 DB `system_config`、再回退环境变量**：

```python
db_val = _get_db_config("auth_enabled")
if db_val:
    return db_val.lower() == "true"
return _env_bool("AUTH_ENABLED", "true")
```

所以若前面的用例把开关写进了 **DB**，只钉环境变量根本不起作用——**我的一行方案会漏**。Q 补上了对配置读取函数的钉法。
