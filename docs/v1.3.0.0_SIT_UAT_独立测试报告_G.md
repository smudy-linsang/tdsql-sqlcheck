### 2. BUG-130-02 (响应字段 `reports` vs `items`) 证据确凿

- **争议焦点**：Mavis 认为 `/api/v1/audit/extracted-reports` 应改为 `items` 以符合 API 文档。
- **智能体 G 铁证代码**：
  在前端核心主代码 `frontend/static/js/app.js` 第 735 行：
  ```javascript
  const loadExtractedReports = async () => {
    extractedReportsLoading.value = true;
    try {
      const resp = await apiFetch(`${API_BASE}/api/v1/audit/extracted-reports`);
      if (resp.ok) {
        const d = await resp.json();
        extractedReports.value = d.reports || []; // <--- 关键点：前端写死了 d.reports！
      }
    } catch(e) {}
    finally { extractedReportsLoading.value = false }
  };
  ```
- **结论**：后端代码 `sql_audit.py` 返回 `"reports": report_list` 属于**必须保留的向下兼容约定**。若强行修改为 `items`，前端历史报告列表将崩溃（空显示）。**智能体 A 驳回 BUG-130-02 完全正确**！
