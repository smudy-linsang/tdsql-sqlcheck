# v1.6.2.2 内网生产扫描结果回放对比证据

本目录保存智能体O于 2026-08-30 对三组 v1.6.2.1 内网生产报告与 v1.6.2.2 开发环境报告进行独立核查后的脱敏汇总。

## 证据边界

- 六份原始 HTML 位于用户本机 OneDrive，包含内部 SQL、表名和注释，**未复制到 Git 仓库**。
- `comparison-summary.json` 只保存报告哈希、计数和版本差分，不保存 SQL 原文。
- 三组共 802 条 SQL 在数量、顺序及归一化内容上完全一致。
- 旧报告来自在线元数据审核，新报告来自文件审核；直接相减混合了入口和规则集差异，不能证明版本因果。
- 为隔离纯版本差，使用新报告还原的同一批 SQL，在 v1.6.2.1 发布点 `f99de2a` 与 v1.6.2.2 上走同一 `RuleChecker.audit_file(instance_type="distributed")`、同一默认规则集复跑，并比较到完整违规消息。
- 结论仅覆盖本次提供的三组、共 802 条 SQL 样本，不替代 119 条规则全域测试。

## 核心结果

- 同入口双版本复跑：802/802 条语句一致，1,858/1,858 条命中一致；新增、消失、严重度变化、消息变化全部为 0。
- HTML 直接差分中的 R033/R036/R037 均来自已确认的生产关闭、开发启用规则开关差异。
- 26 条 R033 在 v1.6.2.1 同入口复跑中同样存在，进一步证明不是 v1.6.2.2 引入。
- 三组样本不包含 `UNIQUE INDEX ... COMMENT` 或 `PRIMARY KEY ... COMMENT`，不能单凭这些附件证明原始崩溃用例已关闭。

完整方法、结论和投产建议见配套评估报告。
