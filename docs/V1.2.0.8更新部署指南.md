# TDSQL SQL审核工具 V1.2.0.8 更新部署指南

> **适用对象**：内网自动化部署智能体 / 运维工程师  
> **发布日期**：2026年7月26日  
> **建议部署时间**：任意维护窗口（升级过程服务短暂重启 < 5秒）

---

## 📌 核心更新点 (v1.2.0.8)

1. **大规模集群 (100+ 服务器) 巡检对比与 HTML 大屏崩溃问题全面重构**：
   - **实例级 & 服务器级单机聚焦比对**：新增 `el-select` 节点与服务器 IP 独立下拉筛选，支持 100+ 服务器场景下选择单台 IP/节点独立精准比对；
   - **界面 DOM 极速切片分页**：界面表格引入前端 `el-pagination`，默认按 15/30/50 条切片渲染，内存 DOM 节点数减少 99%，**告别无响应与网页挂死**；
   - **离线 HTML 对比大屏按需渲染与轻量分页**：导出的 HTML 对比大屏注入原生无依赖轻量 JS 分页与 IP 切换控制栏，超大集群图表报告浏览器中**秒开、流畅滚动**。
2. **菜单栏侧边图标全系精致统一**：
   - 补全【慢SQL治理】`<Timer />` 图标与【深度诊断】`<Cpu />` 硬件核心诊断图标，保持系统视觉风格一致统一。

## 📦 一键升级/部署步骤（给内网部署智能体）

内网部署智能体可直接执行以下一键安装/更新指令：

### 1. 解压发布包
```bash
tar -zxvf tdsql-sqlcheck-v1.2.0.8-linux-x86_64.tar.gz
cd tdsql-sqlcheck-v1.2.0.8
```

### 2. 自动化前置检查与一键安装
```bash
# 检查运行环境 (端口 8000、Python 依赖等)
bash deploy/preflight_check.sh

# 一键安装升级 (自动保持现有配置与数据库，零破坏升级)
bash deploy/install.sh
```

### 3. 部署验证
```bash
# 检查 8000 端口服务状态
curl -s http://localhost:8000/api/v1/health | grep "ok"
```

---

## ↩️ 一键回滚机制

如部署过程中遭遇异常，可直接使用内置的回滚脚本恢复至上个版本：

```bash
bash deploy/rollback.sh
```

---

## 💡 给内网部署智能体的特权建议

1. **便携 Python 自动适配**：如果服务器没有外网且缺少标准 `python3.11`，系统会自动优先读取 `/opt/python311/python/bin` 免编译便携 Python 环境；
2. **零数据丢失保障**：`install.sh` 脚本在覆盖前会自动备份 `data/tdsql_check.db` 与 `config.py`，无缝保留历史巡检与规则配置。
