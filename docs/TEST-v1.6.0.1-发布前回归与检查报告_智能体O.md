- 产品版本：v1.6.0.1

- 测试执行与报告作者：智能体O

## 1. 本版变更与边界

本版的发布目标为将已实现但当前不具备稳定可运维条件的“原始慢日志”能力整体下线，并保留已完成的 ZooKeeper（ZK）自动发现能力。

| 范围 | v1.6.0.1 处理结果 | 验收要点 |
|---|---|---|
| 原始慢日志前端 | 菜单、页面和采集源抽屉默认不可见 | 普通用户与管理员均没有产品入口 |
| 原始慢日志权限 | 不出现在权限矩阵、默认角色权限或菜单元数据中 | 旧页面和手工请求不能重新授予该菜单权限 |
| 原始慢日志 API | 全部 `/api/v1/raw-slowlogs/*` 入口默认返回 HTTP 404 | 不会读取历史采集源、不会触发 Probe 或采集 |
| 原始慢日志调度 | 默认不注册轮询任务；运行中再次关闭也会在租约前返回 | 不会意外连接日志主机 |
| 历史数据与代码 | 保留，不删除数据库表、事件、实现代码 | 后续独立评审后可重新设计恢复 |
| 发布包 | 不携带远端导出器、构建脚本和原始慢日志相关运行文档 | 不会把未启用能力交付到目标环境 |
| ZK 自动发现 | 保留运行配置页、加密保存认证口令、真实发现失败显式报错及诊断日志 | 不返回 Mock 实例，不静默降级 |

功能开关为 `RAW_SLOWLOG_ENABLED`，默认值为 `false`。任何恢复动作均应另立需求、完成安全评审和变更审批；本版不应将其设为 `true`。

## 4. ZK 自动发现检查结论

1. 本版没有回退到 Mock：真实发现请求在配置缺失、节点不可达、客户端不可用或脚本失败时应显式失败；不得返回模拟实例，也不得把模拟结果写入实例类型权威来源。
2. 配置入口、认证口令加密存储、内外网地址映射、发现日志和失败诊断的自动化测试均已回归通过。
3. 云上开发环境此前已证实 ZK 本机 CLI 可以读取根节点和实例集合；公网映射入口出现客户端握手超时，属于网络路径问题，不能以此替代产品真实链路验收。
4. 因此，本版可以进入打包流程，但**内网部署后必须由具备 ZK 可达网络的执行人员完成一次真实发现验收**：保存配置、开始扫描、确认发现结果中包含集中式和分布式实例、导入一条非生产测试实例，并核查 `ZK_DISCOVERY_*` 日志。若该步骤失败，应依据诊断日志处置，不得开启任何 Mock 降级。
