# v1.2.0.9 Upgrade Manual (English Version)

## 📌 Release Summary (v1.2.0.9)

- **Dashboard Audit Trend Auto-render Fix**:
  - Resolved an issue where the "7-Day Audit Trend" chart failed to render automatically upon initial user login.
  - Implemented width-sensing retry logic and auto-render dispatching during `loadAll()`.
- **Verify Deploy Script Improvement**:
  - Updated `deploy/verify_deploy.sh` to dynamically read the expected version from `VERSION` instead of static hardcoding.
- **Documentation Packaging**:
  - Dynamically includes all `docs/*.md` files into the release bundle.
