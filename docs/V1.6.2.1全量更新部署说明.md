# TDSQL-SQLCheck V1.6.2.1 全量更新部署说明

## 1. 介质文件

| 文件名 | 说明 |
|---|---|
| `tdsql-sqlcheck-v1.6.2.1-linux-x86_64.tar.gz` | Linux x86_64 全量独立发布包（包含离线 wheels 与全部静态资源） |
| `tdsql-sqlcheck-v1.6.2.1-linux-x86_64.tar.gz.sha256` | SHA256 校验和文件 |

---

## 2. 部署前准备

1. **环境要求**：
   - 操作系统：CentOS 7+ / RHEL 7+ / TencentOS 2+ / Ubuntu 18.04+
   - Python 版本：Python 3.8 ~ 3.11（推荐 Python 3.10+）
   - 系统权限：具备 `sudo` 权限的运维账号
2. **端口确认**：确认 `8000` 端口或指定端口未被占用。

---

## 3. 标准部署操作

### 第一步：介质完整性核验
```bash
cd /tmp
sha256sum -c tdsql-sqlcheck-v1.6.2.1-linux-x86_64.tar.gz.sha256
```

### 第二步：解包与一键安装
```bash
tar -zxvf tdsql-sqlcheck-v1.6.2.1-linux-x86_64.tar.gz
cd tdsql-sqlcheck-v1.6.2.1
sudo ./deploy/install.sh --install-dir /opt/tdsql-sqlcheck
```

### 第三步：验证安装
```bash
sudo /opt/tdsql-sqlcheck/current/deploy/verify_deploy.sh
```

---

## 4. 关键特性与防呆机制说明

1. **数据库密码解密密钥继承（Zero Data Loss）**：
   - `install.sh` 脚本在安装新版本目录时，会自动检测历史版本中的 `TDSQL_ENCRYPTION_KEY` 环境变量与 `data/encryption.key` 文件，并自动同步写入 `.env`。
   - 升级后无需重新录入数据库密码，实例管理与元数据提取直接可用。
2. **平滑回滚**：
   - 历史版本目录完整保留在 `/opt/tdsql-sqlcheck/releases/` 下，可通过 `.previous_release` 软链实现秒级回退。
