# v1.2.0.8 Upgrade Manual (English Version)

## 📌 Release Summary (v1.2.0.8)

- **Large Cluster Daily Inspect & Compare Refactoring**:
  - Implemented single Node / Server IP dropdown selection (`el-select`) for targeted metric comparison.
  - Implemented high-performance client-side pagination (`el-pagination`) for Vue tables to prevent DOM explosion on 100+ server clusters.
  - Upgraded HTML report export with light-weight Vanilla JS pagination engine and sticky header selection controls.
- **Sidebar Menu Aesthetics**:
  - Added `<Timer />` for Slow SQL Governance.
  - Added `<Cpu />` for Deep Diagnosis.

## 🚀 Quick Deployment Guide

```bash
tar -zxvf tdsql-sqlcheck-v1.2.0.8-linux-x86_64.tar.gz
cd tdsql-sqlcheck-v1.2.0.8
bash deploy/preflight_check.sh
bash deploy/install.sh
```
