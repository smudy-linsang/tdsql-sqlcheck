## 4. 需求③　换行治理（按盒模型实测，不靠肉眼）

截图看着不换行不能算数——**可能是不换行但被裁掉了**。所以我量的是三件事：行数、内容宽 vs 列宽、以及最后一个按钮的右边界有没有越出单元格。

```
    地址列: 行数=1 溢出=0px white-space=nowrap
    操作列: 行数=1 溢出=0px white-space=nowrap
  ✅ ★地址列内容单行显示        ✅ ★地址列内容未溢出列宽
  ✅ ★操作列按钮单行显示        ✅ ★操作列内容未溢出列宽

    表头(文本, 行数, 溢出px):
      连接名 1行 +0  地址 1行 +0  用户名 1行 +0  类型 1行 +0  状态 1行 +0
      默认 1行 +0   ERROR上限 1行 +0   WARNING上限 1行 +0   操作 1行 +0
  ✅ ★「WARNING上限」表头单行显示     ✅ ★「WARNING上限」表头未溢出
  ✅ 其余表头也无换行                 ✅ 页面整体无横向滚动
```

**逐个按钮量右边界**（证伪"不换行但被裁"）：

```
    按钮数=7  按钮占用=378px  单元格内宽=480px  越界=-90px  按钮所处行数=1
  ✅ ★操作列按钮全部在一行（顶端坐标只有 1 个）
  ✅ ★最后一个按钮未越出单元格右边界（没被裁）
  ✅ 操作列有余量 — 占用 378 / 480px
```

7 个按钮（连接/设为默认/编辑/探测类型/锁定类型/探测诊断/删除）正是按钮最多的那种行，占 378px，**480px 的列宽还余 90px**，不是刚好卡住。

**四种分辨率下复量**（操作列从 360 加宽到 480，怕在窄屏挤出横向滚动）：

```
  1920x1080: 页面横向溢出=0px  表体横向滚动=0px  操作按钮行数=1 越界=-90px
  1600x950 : 页面横向溢出=0px  表体横向滚动=0px  操作按钮行数=1 越界=-90px
  1440x900 : 页面横向溢出=0px  表体横向滚动=0px  操作按钮行数=1 越界=-90px
  1366x768 : 页面横向溢出=0px  表体横向滚动=0px  操作按钮行数=1 越界=-90px
```

**连 1366×768 这种老办公屏都没有横向滚动**，加宽没有副作用。

## 5. A-P3-03（新，P3，不阻断）：地址列 260px 的余量与"看不到全文"

需求写的是"地址字段的内容必须要一行全部显示出来"。**"一行"做到了；"全部显示"在地址够长时做不到**——超出部分变成省略号，而且**悬停没有 tooltip**，运维无从得知被截掉了什么。

用一组长度递增的真实形态地址量出确切阈值：

| 地址 | 字符数 | 需要 px | 列内宽 | 结果 |
|---|---:|---:|---:|---|
| `10.243.15.146:16001/cfs` | 23 | 138 | 260 | 完整显示 |
| `10.243.13.150:16002/sungl_busi` | 30 | 181 | 260 | 完整显示 |
| `10.243.15.197:16003/tdsql_sqlcheck` | 34 | 204 | 260 | 完整显示 |
| `10.243.13.150:16004/unified_payment_biz` | 39 | 236 | 260 | 完整显示 |
| `10.243.100.100:16005/aps_coredb_settlement` | 42 | 259 | 260 | 完整显示（**只余 1px**） |
| `10.243.15.197:16006/tdsql_sqlcheck_metadata` | 43 | 263 | 260 | ★**被省略号截断** |
| `10.243.15.197:16007/tdsql_sqlcheck_metadata_db` | 46 | 284 | 260 | ★**被省略号截断** |

- **阈值是 42 字符**；
- **内网现有最长地址 34 字符**（`10.243.15.197:15197/tdsql_sqlcheck`，204px），**还富余约 9 个字符**——所以当前数据是安全的；
- 但 ZK 标准化导入是**一个业务库一条连接**，业务库名长一点（如 `unified_payment_settlement`）就会越线；
- 越线后**没有任何补救**：`地址` 列没有 `show-overflow-tooltip`（对照：`连接名` 列有），悬停实测 tooltip 为空。

**修法（二选一，都很小）**：

1. 给地址列加一个属性（推荐，改动最小、且与连接名列口径一致）：
   ```html
   <el-table-column label="地址" width="260" class-name="td-nowrap" show-overflow-tooltip>
   ```
2. 或把固定 `width="260"` 改为 `min-width="260"`，让列随可用空间自然伸展（实测 1366 屏仍有余量，不会撑出横向滚动）。

**补用例**：造一条 ≥43 字符的地址 → 断言**单行**且**悬停可读全文**（只断言"不换行"抓不到这条）。
