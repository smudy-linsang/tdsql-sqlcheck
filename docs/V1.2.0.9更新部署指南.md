## 📌 核心更新点 (v1.2.0.9)

1. **【治理概览】近7天审核趋势图自动渲染优化**：
   - 修复了用户首次登录系统或刷新数据时，“近7天审核趋势”图表未自动初始化渲染、需点击切换菜单才显示的缺陷；
   - 增加了 DOM 容器宽度防抖重试与 `loadAll()` 阶段的自动渲染调配，确保**登录/刷新首帧图表 100% 极速呈现**。
2. **【验证脚本】消除版本硬编码**：
   - `deploy/verify_deploy.sh` 脚本全面改造为**动态读取根目录 `VERSION` 文件**，彻底杜绝内网智能体升级校验时的硬编码历史问题。
3. **【部署打入】全量文档随包动态打包**：
   - 重构发布打包流程，实现了 `docs/*.md` 下所有部署指南与内网交付标准建议文档的全自动化打入。

## 📦 一键升级/部署步骤（给内网部署智能体）

### 1. 解压发布包
```bash
tar -zxvf tdsql-sqlcheck-v1.2.0.9-linux-x86_64.tar.gz
cd tdsql-sqlcheck-v1.2.0.9
```

### 2. 前置检查与一键安装
```bash
# 检查运行环境
bash deploy/preflight_check.sh

# 一键平滑安装升级 (零破坏、数据无损保留)
bash deploy/install.sh
```

### 3. 一键部署冒烟验证
```bash
# 运行部署验证脚本 (已支持动态版本校验)
bash deploy/verify_deploy.sh
```
