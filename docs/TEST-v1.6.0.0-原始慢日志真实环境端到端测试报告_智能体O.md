## 2. 发现并修复的缺陷

真实日志的时间字段为：

```text
# Time: YYMMDD HH:MM:SS 微秒
```

例如格式为 `260731 13:45:06 303896`。原实现仅支持无微秒的紧凑格式和带 `T`/`.` 的常见格式，导致 Python 解析器将块判定为 `unsupported # Time`；Go 导出器的 `lookback` 定位同样无法解析该格式。

已修复：

- `backend/services/raw_slowlog_parser.py`：支持 `%y%m%d %H:%M:%S %f`；
- `deploy/raw_slowlog_exporter/main.go`：显式解析“空格分隔微秒”的 TDSQL 紧凑时间；
- 新增 Python 与 Go 回归测试，锁定该真实格式。
