## 一、 版本核心变更与架构升级总览 (V1.6.0.4 ➔ V1.6.0.7)

从 V1.6.0.4 全量升级至 V1.6.0.7，系统完成了以下四大核心架构升级与关键修复：

1. **ZooKeeper 发现会话与预览元数据库持久化 (Fernet 加密)**：
   - 解决多 Worker 部署场景下内存 Session/Preview 丢失引起的 `410 Gone` 错；
   - 所有会话数据与临时探查凭据通过 Fernet 对称加密后存储于系统数据库。

2. **扫描期富集与五级名称自适应解析链**：
   - 支持在 ZK 拓扑扫描期自动富集 MonitorDB 元数据（实例名称与可访问业务库）；
   - 提供自适应五级解析链（用户手动覆盖 ➔ 扫描期富集 ➔ 链式解析）；
   - 增加 IP 网段批量替换规则与五维维度筛选。

3. **数据库 Schema 迁移升级 (v10 架构)**：
   - `zk_discovery_config` 增加扫描富集配置列（`octet_rules_json`、`monitor_host`、`monitor_port`、`monitor_user`、`monitor_db`、`enrich_enabled`）；
   - `zk_discovery_import_items` 增加来源留痕列（`name_source`、`databases_source`）。

4. **异常归一与连接凭据安全防护 (v1.6.0.6 追加修复)**：
   - 统一建立连接异常捕获为 `DB_CONNECT_FAILED` / `MONITOR_CONNECT_FAILED`，防止批量预检时触发 500 级中断；
   - 用户名/口令清空时自动清除已保存凭据密文，避免继承历史敏感配置。

## 二、 核心重点：元数据库（System Meta-Database）变更与自动迁移详解

**在升级至 V1.6.0.7 过程中，后台服务启动时会自动安全地应用增量 Schema 迁移文件（含 v7 原始慢日志、v8 ZK配置、v9 连接唯一约束、v10 扫描富集与留痕 `backend/schema/v10/100_zk_scan_enrich.sql`）以及 `migrator.run_migrations()`，无需运维人员手动执行 DDL 脚本。**

以下为 v10 元数据库变更清单：

### 1. `zk_discovery_config` 表新增富集列
- `octet_rules_json` (TEXT)：IP 网段批量替换规则 JSON；
- `monitor_host` / `monitor_port` / `monitor_user` / `monitor_db`：MonitorDB 探查服务配置；
- `monitor_password_encrypted` / `business_password_encrypted`：Fernet 密文口令列；
- `enrich_enabled` (TINYINT)：扫描期富集开关。

### 2. `zk_discovery_import_items` 表新增留痕列
- `name_source` (VARCHAR(32))：实例名称解析来源留痕；
- `databases_source` (VARCHAR(32))：业务库列表探查来源留痕。

## 三、 全量部署与安装操作步骤（内网运维智能体执行）

### 1. 解压全量发布包与部署预检
```bash
# 解压全量发布包
tar -zxvf tdsql-sqlcheck-v1.6.0.7-linux-x86_64.tar.gz
cd tdsql-sqlcheck-v1.6.0.7

# 执行部署预检（要求全 PASS，验证依赖与环境健康）
bash deploy/preflight_check.sh
```

### 2. 配置文件校验 (`deploy/.env`)
核对并更新 `deploy/.env` 配置文件中的元数据库与网络参数：
```ini
SQLCHECK_DB_HOST=127.0.0.1
SQLCHECK_DB_PORT=13306
SQLCHECK_DB_USER=root
SQLCHECK_DB_PASSWORD=tdsql_test_2024
SQLCHECK_DB_NAME=tdsql_sqlcheck
AUTH_ENABLED=true
ADMIN_INITIAL_PASSWORD=Admin@1234
```

### 3. 执行全量安装与服务升级重启
```bash
# 执行安装脚本（停止已有服务、覆盖全量代码、重新安装 wheels 依赖、升级数据库 Schema）
sudo ./deploy/install.sh
```
> ⚠️ **重要提醒**：`kazoo` 为本版必配离线依赖。全量安装时**必须完整运行 `./deploy/install.sh`（或执行 `pip install --no-index --find-links wheels/ -r requirements.txt`）**，切勿仅手动替换代码目录。

### 4. 上线最后自检 (必做步骤)
```bash
# 在目标部署机上运行部署校验脚本
bash deploy/verify_deploy.sh
```
`verify_deploy.sh` 会自动检测 Uvicorn 进程、端口监听、版本比对（输出 `1.6.0.7`）与 `/health` 端点，全部输出 PASS 即代表升级成功。
