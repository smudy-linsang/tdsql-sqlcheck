## 一、 评估范围与版本特性总览

V1.6.0.0 是系统的重大版本升级，重点完成了以下核心功能与架构提升：

1. **「慢SQL治理 / 原始慢日志」独立子模块 (SSH Exporter V1)**：
   - 解决了现有 `monitordb`（仅有采集时刻）、`digest`（无历史窗口）、`processlist`（无历史记录）在逐条慢 SQL 追溯上的痛点；
   - 引入 CheckSQL 部署机经内网 SSH 只读拉取 Proxy/Gateway 日志块的采集链路；
   - 增加 `slow_log_sources`, `slow_log_source_nodes`, `slow_log_cursors`, `slow_log_events`, `slow_log_runs` 5 张 V7 数据库新表。
2. **统一 SQL 脱敏与 SHA-256 指纹服务 (`sql_masking.py`)**：
   - 规范了全局 SQL 模板化、字面量遮蔽、指纹计算与 8 KiB 超长展示截断机制。
3. **安全与受限采集架构**：
   - 远端使用 Go 编写静态受限导出器 (`raw_slowlog_exporter`)，基于 ForceCommand 与白名单路径隔离；
   - 强制 OpenSSH 严格主机指纹校验与 Secret 引用，严禁口令与 root 访问。

## 四、 真实环境投产准入门禁要求

为确保 V1.6.0.0 原始慢日志模块在内网生产环境安全运行，投产前必须满足以下门禁：
1. **只读账号与受限 Export**：目标 Proxy/Gateway 主机必须配置专用的 `tdsql_log_reader` 只读账号，并使用 `ForceCommand` 限制为可执行 `raw_slowlog_exporter`。
2. **凭据隔离**：SSH 密钥和 known_hosts 指纹文件需置于部署机受控目录，严禁硬编码或入库。
3. **格式探查校验**：添加新采集源后需先调用 Probe 验证导出器版本（1.x）及慢日志格式签名。
