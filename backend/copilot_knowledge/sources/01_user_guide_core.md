# 即时审核

即时审核入口在左侧菜单“即时审核”（audit-sql）。把 SQL 粘贴进编辑器，选择实例类型（分布式/集中式，不确定可选 unknown），点击“开始审核”。审核结果按规则号 R 开头列出，分 ERROR、WARNING、INFO 三个级别。ERROR 必须修复后才能过质量门禁。

审核结果只代表当前规则集与当前输入文本的静态结论，不等于在数据库实际执行通过。

# 文件审核

文件审核入口在“文件审核”（file-audit）。上传 .sql 文件或粘贴多段 SQL，系统逐条审核并生成报告。大文件审核是异步任务，提交后在任务列表查看进度；任务失败先查看错误码与阶段信息。

# 在线元数据审核

在线元数据审核入口在“在线元数据审核”（schema-extractor-audit）。它从已授权的 TDSQL 实例提取库表结构并执行审核。任务需要 metadata-runner 执行器在线；页面提示“执行器不可用”时请联系管理员检查 tdsql-metadata-runner 服务。

任务失败排查顺序：先看任务状态与阶段（phase），再看错误码（error_code），最后看是否有资源类记录。没有看到退出码或内存证据时，不能直接断定是内存不足。

# 慢SQL记录与EXPLAIN分析

慢 SQL 记录在“慢SQL记录”（slow-records）。每条记录包含指纹、执行耗时、扫描行数等指标。EXPLAIN 分析在“EXPLAIN分析”（explain），只能基于已经保存的执行计划解读；没有保存计划时系统会明确提示缺失，不会伪造实时结果。

# 扫描结果对比

扫描对比入口在“扫描结果对比”。对比要求同模块、同实例、同库的两个快照。规则版本不同或口径不同的快照不能直接得出“问题已修复率”结论。

# 表类型统计

表类型统计在“深度诊断-表类型统计”（deep-diag-tabletype）。统计区分主表、物理子表、逻辑总表，质量状态分 COMPLETE、PARTIAL、UNKNOWN。PARTIAL 表示统计不完整，UNKNOWN 表示未知，两者都不是 0。

# 网关日志分析

网关日志分析在“深度诊断-网关日志分析”（deep-diag-gateway）。解读基于已上传日志的结构化分析摘要；没有结构化摘要的旧报告需要回到原页面查看。

#  Copilot 专家助手

Copilot 专家助手是本平台的只读建议助手。它可以解释审核结果、解释规则、协助排查任务失败、解读已有报告。它的回答是建议性质，不是正式审核结论，也不代替人工复核与签署。

助手不能执行 SQL、不能修改审核结果、不能自动修复问题。涉及生产变更时，请按变更管理流程在目标库上人工操作。
